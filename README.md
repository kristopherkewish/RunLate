# RunLate

A live departures board for Footscray station in Melbourne, styled after the screens on the platforms. It shows Metro trains on platforms 1, 2, 5 and 6, plus V/Line departures from platform 4, with live delays, cancellations and disruption alerts. Installable as a PWA, and also suitable for a full-screen display.

Built with SvelteKit on Cloudflare Workers, using Transport Victoria's GTFS Schedule and GTFS-Realtime open data.

This is an unofficial hobby project, not affiliated with Metro Trains Melbourne, V/Line or Transport Victoria. The timetable and real-time data are © State of Victoria (Department of Transport and Planning), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
